## 1. 기본 전략 (BasicStrategy)

기본 전략은 가장 보편적인 기술적 지표를 활용하여 종목을 분석하고 선정합니다.

### 사용하는 기술적 지표
- **이동평균선(Moving Average)**: 단기/장기 이동평균선 교차 시점 분석
- **RSI(상대강도지수)**: 과매수/과매도 구간 판단
- **볼린저 밴드**: 가격 변동성 및 추세 반전 시점 파악

### 매수 신호
- **골든 크로스 발생**: 단기 이동평균선이 장기 이동평균선을 상향 돌파
- **RSI 과매도 상태**: RSI가 30 이하로 떨어짐
- **볼린저 밴드 하단 돌파**: 가격이 볼린저 밴드 하단을 하향 돌파

### 매도 신호
- **데드 크로스 발생**: 단기 이동평균선이 장기 이동평균선을 하향 돌파
- **RSI 과매수 상태**: RSI가 70 이상으로 상승
- **볼린저 밴드 상단 돌파**: 가격이 볼린저 밴드 상단을 상향 돌파

### 주요 설정값
| 파라미터 | 기본값 | 설명 |
|---------|-------|------|
| ma_short | 5 | 단기 이동평균선 기간(일) |
| ma_long | 20 | 장기 이동평균선 기간(일) |
| rsi_period | 14 | RSI 계산 기간(일) |
| rsi_oversold | 30 | RSI 과매도 기준 |
| rsi_overbought | 70 | RSI 과매수 기준 |
| bb_period | 20 | 볼린저 밴드 기간(일) |
| bb_std | 2 | 볼린저 밴드 표준편차 |
| stop_loss | 0.03 | 손절 기준 (3%) |
| take_profit | 0.05 | 익절 기준 (5%) |
| max_position | 5 | 최대 포지션 개수 |
| position_size | 0.2 | 포지션 크기 (자본금 대비 20%) |

## 2. 고빈도 전략 (HighFrequencyStrategy)

고빈도 전략은 1분 간격으로 코스피 종목을 스캐닝하여 빠르게 상승하는 종목을 포착하고 단기 매매합니다.

### 종목 선정 과정

#### 1차 빠른 필터링
- **가격 변동 점수**:
  - 3% 이상 상승: 3점
  - 1% 이상 상승: 2점
  - 상승 중: 1점
- **거래량 점수**:
  - 평균 대비 300%: 3점
  - 평균 대비 200%: 2점
  - 평균 대비 100%: 1점
- **기준**: 총점 4점 이상인 종목만 2차 분석 대상

#### 2차 상세 지표 분석 (10점 만점)
- **이동평균선**:
  - 골든크로스 발생: +2점
  - 5일선이 10일선 위: +0.5점
- **볼린저 밴드**:
  - 하단 근처(5% 이내): +1.5점
  - 상단 돌파: +1점
- **RSI**:
  - 과매도 탈출 구간(30-50): +1.5점
  - 상승 구간(50-70): +1점
- **거래량**:
  - 평균 대비 2배 이상: +2점
  - 평균 대비 1.5배 이상: +1점
- **일중 강도**: 분봉 데이터 기준 상승 비율에 따라 최대 2점

#### 최종 후보 선정
- 종합 점수가 임계값(기본 5.0) 이상인 종목만 선정
- 점수 순으로 정렬하여 상위 종목부터 매수

### 주요 설정값
| 파라미터 | 기본값 | 설명 |
|---------|-------|------|
| scan_interval | 1 | 스캐닝 간격(분) |
| top_stock_limit | 100 | 상위 종목 스캐닝 개수 |
| mid_stock_limit | 300 | 중위 종목 스캐닝 개수 |
| candidate_limit | 10 | 최대 매수 후보 수 |
| score_threshold | 5.0 | 매수 후보 최소 점수 (10점 만점) |
| api_call_delay | 0.2 | API 호출 간 딜레이(초) |
| entry_time_start | 09:00 | 매수 시작 시간 |
| entry_time_end | 15:20 | 매수 종료 시간 |
| exit_time | 15:25 | 청산 시간 |

## 3. ML 기반 고빈도 전략 (MLHighFrequencyStrategy)

머신러닝 모델의 예측과 기술적 지표를 결합하여 더 정교한 종목 선정과 매매 결정을 수행합니다.

### 종목 선정 과정

#### 1차 필터링
- **가격 범위**: 5,000원 ~ 100,000원
- **거래량**: 평균 대비 130% 이상
- **가격 변동**: 상승 중인 종목
- **초기 점수**: 가격 변동과 거래량에 따라 0-10점 부여, 3점 이상인 종목 선택

#### 종합 분석 (최종 점수 계산)
- **기술적 지표 분석** (40% 가중치):
  - 이동평균선 배열 분석
  - RSI 구간 분석
  - 볼린저 밴드 위치 분석
  - 거래량 증가율 분석
  - 분봉 데이터에서 상승봉 비율 분석
  
- **ML 모델 예측** (40% 가중치):
  - 학습된 모델이 상승 가능성 예측 (랜덤 포레스트, LSTM, 트랜스포머 등)
  - 특성 엔지니어링을 통해 데이터 전처리
  
- **모멘텀 분석** (20% 가중치):
  - 1일, 5일, 10일 가격 변화율 분석
  - 가격 변화 가속도 측정
  - 일간 변화율 고려

#### 최종 선정
- 종합 점수가 임계값(7.5) 이상인 종목 선정
- 점수 순으로 정렬하여 상위 종목부터 매수

### 주요 설정값
| 파라미터 | 기본값 | 설명 |
|---------|-------|------|
| scan_interval | 1 | 스캐닝 간격(분) |
| top_stock_limit | 150 | 스캐닝 종목 수 |
| score_threshold | 7.5 | 매수 임계점수 (10점 만점) |
| volume_threshold | 1.3 | 거래량 증가 임계값 (130%) |
| max_price | 100000 | 최대 매수 가격 |
| min_price | 5000 | 최소 매수 가격 |
| stop_loss | 0.01 | 손절 기준 (1%) |
| take_profit | 0.02 | 익절 기준 (2%) |
| trailing_stop | 0.005 | 트레일링 스탑 (0.5%) |
| position_size | 0.05 | 포지션 크기 (자본금 대비 5%) |
| max_positions | 10 | 최대 포지션 개수 |
| max_holding_time | 60 | 최대 보유 시간(분) |
| ml_weight | 0.4 | ML 예측 가중치 |
| technical_weight | 0.4 | 기술적 지표 가중치 |
| momentum_weight | 0.2 | 모멘텀 가중치 |

## 4. 종목 선정 및 교체 주기

시스템은 다양한 주기로 종목을 선정하고 교체합니다:

- **고빈도 전략**: 1분 간격으로 매매 후보 스캐닝
- **ML 기반 고빈도 전략**: 10분마다 매매 후보 재평가
- **주간 업데이트(weekly_update)**: 주 단위로 종목 갱신
- **자동 재학습(auto_retrain)**: 일정 주기(기본 7일)로 ML 모델 재학습

ML 모델 성능이 임계값(65%) 아래로 떨어지면 자동으로 재학습을 진행합니다.

## 5. 종목 정보 수집 방법

시스템은 한국투자증권 API를 통해 다양한 종목 정보를 수집하고 분석합니다:

- **일별 주가 데이터**: 종가, 시가, 고가, 저가, 거래량
- **분봉 데이터**: 1분 단위 가격 및 거래량 변화
- **현재가 정보**: 실시간 시세 및 호가 정보
- **거래량 정보**: 일평균 대비 거래량 비율
- **시가총액 정보**: 종목 규모 및 시장 영향력 파악

수집된 데이터는 전처리를 거쳐 기술적 지표 계산 및 ML 모델 입력에 사용됩니다.

## 6. 매매 결정 과정

### 매수 결정 과정
1. **포지션 확인**: 현재 포지션 개수가 최대치 미만인지 확인
2. **시간 체크**: 현재 매수 가능 시간인지 확인
3. **종목 점수 확인**: 종목 점수가 임계값 이상인지 확인
4. **가격 범위 확인**: 현재 가격이 매수 가능 범위 내인지 확인
5. **주문 실행**: 모든 조건 충족 시 매수 주문 실행

### 매도 결정 과정
1. **청산 시간 확인**: 장 마감 전 청산 시간인지 확인
2. **익절 조건**: 수익률 >= 익절 기준
3. **손절 조건**: 수익률 <= -손절 기준
4. **최대 보유 시간**: 설정된 최대 보유 시간 초과 여부
5. **급락 감지**: 당일 가격이 급락(-3% 이상)했는지 확인
6. **ML 재평가**: 정기적으로 ML 모델 재평가 수행
   - 점수가 임계값의 70% 미만으로 떨어지면 매도

각 전략은 자체적인 매수/매도 결정 로직을 가지며, 전략별 특성에 맞게 파라미터를 조정할 수 있습니다.
